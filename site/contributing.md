# Contributing

Contributions are welcome: new checks, fewer false positives, translations, docs.
See [CONTRIBUTING.md](https://github.com/muka-dev/edeltraud/blob/main/CONTRIBUTING.md)
for the workflow and [SECURITY.md](https://github.com/muka-dev/edeltraud/blob/main/SECURITY.md)
for reporting vulnerabilities in the scanner itself.

- [Open issues](https://github.com/muka-dev/edeltraud/issues)
- [Propose a new check](https://github.com/muka-dev/edeltraud/issues/new?template=new-check.yml)
- [Report a false positive](https://github.com/muka-dev/edeltraud/issues/new?template=false-positive.yml)
- [Discussions](https://github.com/muka-dev/edeltraud/discussions)
